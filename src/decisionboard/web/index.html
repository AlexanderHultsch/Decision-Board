How the board is asked

Individual (default)
One call per ticked member, each answering alone, then one call that consolidates. Members cannot see each other, so disagreements stay visible.
Cost: one call per member, plus one.

Combined
One call receives every ticked profile, the KPI notes and the same knowledge, and writes all entries and the direction in one pass. One model writes them all and sees the earlier entries while writing the later, so fewer disagreements surface.
Cost: one call. Good for a quick first opinion, follow-ups and topics that concern few swim lanes.

In both modes the program checks that every member came back, that each entry names its own measures or tasks, and every citation.

Knowledge selection

AI assisted (recommended)
The model reads a list of candidate sections with their summaries and picks, per member, what that member needs, with a reason you can read.
Pro: picks by meaning, knows synonyms, improves as the vault grows.
Con: one extra call per question, about the size of one member call; the model can pick wrongly, so the picks are shown below before the board runs.
Cost: one call more.

Python only
The program ranks sections by how often the question's words and the member's own words appear, plus the page properties (lead, affected swim lanes, phase).
Pro: free, instant, the same result every time.
Con: literal; misses pages that say the same thing in other words; weaker as the vault grows.
Cost: none.
